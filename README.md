# ITEM

ITEM is the artifact canon for Aeternum Immutablis / AETIMM.

It preserves durable symbolic objects as schema-valid records, candidate artifacts, governance doctrine, and implementation-ready specifications.

ITEM is not the execution engine. ITEM defines what is worth preserving.

## Start here

- `GOVERNANCE.md` — artifact lifecycle and route decisions
- `ROUTING.md` — repo ownership and boundary rules
- `docs/judgment-standard.md` — canonical canon-vs-slop judgment output
- `docs/governance/single-source-of-truth.md` — authority map
- `docs/canon/item-controlled-vocabulary.md` — controlled vocabulary
- `schemas/item-record.schema.json` — canonical artifact record schema

## Repository map

```txt
/canon       Accepted ITEM records
/candidates  Draft artifacts awaiting judgment
/docs        Source-of-truth doctrine and contributor guidance
/schemas     Machine-readable record contracts
/archive     Deprecated or historical material retained for provenance
/examples    Example records and fixtures
```

## Compression rule

AETIMM is compression, not accumulation.

Keep doctrine only when it is load-bearing, schema-relevant, source-of-truth, or directly useful to contributors. Everything else is refined, archived, rerouted, or deleted.
