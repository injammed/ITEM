# ITEM

ITEM is the artifact canon for Aeternum Immutablis / AETIMM.

It preserves durable symbolic objects as schema-valid records, candidate artifacts, artifact-class doctrine, provenance, and implementation-ready specifications.

ITEM is artifact canon only. It is not an execution engine, orchestration stack, protocol rail, or product runtime.

## Start here

- `AETIMM-GENESIS.md` - sealed v0.1 Genesis horizon and doctrine freeze
- `GOVERNANCE.md` - artifact lifecycle and route decisions
- `ROUTING.md` - repo ownership and boundary rules
- `docs/judgment-standard.md` - canonical judgment output
- `docs/governance/single-source-of-truth.md` - authority map
- `docs/canon/item-controlled-vocabulary.md` - controlled vocabulary
- `schemas/item-record.schema.json` - canonical artifact record schema
- `schemas/contribution.schema.json` - contribution intake schema

## Repository map

```txt
/canon       Accepted and canon-review ITEM records
/candidates  Draft artifacts awaiting judgment
/docs        Source-of-truth doctrine and artifact-class guidance
/schemas     Machine-readable record and intake contracts
/archive     Deprecated or historical material retained for provenance
/examples    Example records and fixtures
```

## Compression rule

AETIMM is compression, not accumulation.

Keep doctrine only when it is load-bearing, schema-relevant, source-of-truth, or directly useful to artifact judgment. Everything else is refined, archived, rerouted, or deleted.
