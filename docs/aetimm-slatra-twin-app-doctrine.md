# AETIMM / SLATRA Twin-App Doctrine

## Purpose

This document defines the mythic-public naming layer for the ITEM / Slop Trough twin-app ecosystem.

The latest mobile concept shows two paired apps or pathways:

```txt
AETIMM = ITEM / enduring value / canon museum
SLATRA = Slop Trough / endless consumption / anti-pattern feed
```

This creates a stronger symbolic interface than ordinary product labels alone.

## Core Polarity

```txt
AETIMM: Enter the museum of enduring value.
SLATRA: Enter the trough of endless consumption.
```

## Product Interpretation

AETIMM is the public-facing mythic name for the ITEM canon path.

SLATRA is the public-facing mythic name for the Slop Trough anti-path.

Together they create a deliberate user choice:

```txt
Preserve or consume.
Refine or scroll.
Canon or slop.
Museum or trough.
Enduring value or endless appetite.
```

## Salt-Grain Constraint

This language is powerful, but it should not be allowed to obscure product clarity.

AETIMM and SLATRA may be used as mythic app labels, onboarding language, modes, or brand layers, but the user must still understand the practical function:

- browse canon
- submit artifacts
- judge submissions
- refine Full-Mode Artifacts
- earn contribution reputation
- collect editions
- identify slop / low-value synthetic media

## Naming Logic

### AETIMM

Feels:

- metallic
- eternal
- archival
- sacred-industrial
- black/gold
- curated
- durable
- canon-bound

Associated product meaning:

```txt
ITEM canon registry
Full-Mode Artifact museum
10,000 future civilization archive
Golden Dust earned through value
```

### SLATRA

Feels:

- wet
- gluttonous
- consumptive
- degraded
- sticky
- anti-canon
- endless feed
- synthetic appetite

Associated product meaning:

```txt
Slop Trough
low-value synthetic media
failed canon submissions
anti-pattern feed
public contrast layer
```

## Onboarding Choice

The first-screen choice should feel like entering two worlds:

```txt
AETIMM
Enter the Museum of Enduring Value

SLATRA
Enter the Trough of Endless Consumption
```

The purpose is not to shame the user. The purpose is to make the difference between canon and slop undeniable.

## User Psychology

The user should understand immediately:

```txt
AETIMM asks me to judge, create, refine, and preserve.
SLATRA shows me what happens when generation loses judgment.
```

The user is choosing not merely an app, but a relation to synthetic media.

## Design Direction

### AETIMM Visual Language

- gold horn / orbital seal
- black obsidian icon
- sacred museum glow
- restrained luxury
- enduring archival feel
- serif title treatment

### SLATRA Visual Language

- trough / broken crown vessel
- wet green-gold slime
- falling dust into consumption basin
- darker, degraded, seductive but wrong
- gluttonous anti-luxury

## Product Law

```txt
AETIMM must never become SLATRA.
```

That means:

- no infinite feed as the core product
- no automatic praise
- no dust for uploads alone
- no engagement farming disguised as canon
- no public voting without curation
- no government/corporate content without disclosure
- no reward loop that turns judgment into cheap labor

## Twin-App Lifecycle

```txt
User creates or encounters artifact
→ artifact is structured as Full-Mode candidate
→ Caechat Gate judges it
→ public/canonical signals accumulate
→ artifact routes to AETIMM, refinement, archive, or SLATRA
```

AETIMM path:

```txt
refine
→ rank
→ earn Golden Dust
→ canon candidacy
→ canonization
→ provenance
→ collectible/cultural afterlife
```

SLATRA path:

```txt
fail
→ expose weakness
→ archive as slop
→ serve as contrast / warning / anti-example
```

## Public Language

Use these carefully:

```txt
Choose your path.
Enter the museum.
Enter the trough.

```

Avoid overclaiming:

```txt

This is objective truth.
This gives financial shares.
This proves cultural value automatically.
```

## Final Compression

AETIMM and SLATRA are the twin symbolic doors of the ITEM ecosystem.

AETIMM is the path of canon.

SLATRA is the path of consumption without judgment.

The entire product exists to make that distinction visible, usable, and culturally real.
