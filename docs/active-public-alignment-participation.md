# Active Public Alignment Participation

## Status

Speculative product mechanic. Salt-grain veto active.

This document explores whether the ITEM / Slop Trough twin-app system can support active public participation, voting, and micro-reward loops without becoming exploitative, manipulative, propagandistic, or legally dangerous.

## Core Idea

Users participate in sorting synthetic media and Full-Mode Artifacts by swiping, voting, ranking, judging, and routing submissions toward either:

```txt
ITEM = canon / preservation / artifacthood
Slop Trough = failed slop / anti-pattern / degraded feed
```

The user is not passively consuming AI media. The user is helping classify cultural output.

## Salt-Grain Constraint

The following must be treated cautiously:

- paying users per swipe
- allowing governments or powerful institutions to inject content
- calling rewards `shares`
- implying democratic truth from swipe totals
- turning judgment into dopamine farming
- making Slop Trough a propaganda laundering system

## Hard Vetoes

### Veto 1 — No exploitation through pennies

Do not build a system that pays people tiny amounts to perform meaningless cognitive labor at scale while presenting it as empowerment.

Micro-rewards are only acceptable if the task has real civic/cultural value and the user understands what they are doing.

### Veto 2 — No securities language

Do not call rewards shares, equity, profit rights, or investment stakes unless there is a real legal structure.

Use safer language:

- Golden Dust
- contribution weight
- curator reputation
- canon influence
- collector access
- participation credit

### Veto 3 — No government slop laundering

If governments, campaigns, agencies, corporations, or institutions can submit content, their identity must be clearly disclosed.

Institutional content must be labeled, audited, and searchable.

### Veto 4 — Voting is signal, not truth

Swipe totals should never be treated as objective truth or automatic canon.

Voting is one signal among:

- Caechat critique
- curator review
- provenance
- originality
- modal depth
- manipulation risk
- community reasoning

### Veto 5 — Slop Trough cannot become the main addiction engine

If Slop Trough becomes more engaging than ITEM, the system has inverted.

Slop Trough is an anti-pattern mirror, not the core value product.

## Product Mechanic: Public Sorting

The user sees a submission and chooses:

```txt
ITEM-worthy
Slop
Needs refinement
Duplicate
Propaganda / manipulation risk
Technically interesting but aesthetically weak
Beautiful but canonically empty
```

This is more precise than simple left/right voting.

## Swipe Actions

Possible actions:

```txt
preserve
reject
refine
flag
compare
rank
route
```

Avoid crude binary voting where possible.

## Reward Logic

A user may earn small Golden Dust rewards for high-quality evaluation, not for raw swipe volume.

Possible reward inputs:

```txt
review accuracy
agreement with later curator judgment
useful critique
manipulation detection
duplicate detection
constructive refinement
canon-relevant classification
```

Do not reward simple speed or engagement.

## Better Than 1 Cent Per Swipe

A flat `1 cent per swipe` model risks creating:

- low-quality judgment farms
- bot activity
- exploitation
- dopamine loops
- adversarial gaming

Better model:

```txt
micro-reward only when judgment quality is validated later
```

Example:

```txt
User flags a submission as duplicate.
System confirms duplicate.
User receives Golden Dust / reputation.
```

Or:

```txt
User writes critique.
Curators mark critique useful.
User receives Golden Dust.
```

## Institutional Submission Layer

Governments, NGOs, corporations, artists, campaigns, and research labs may submit content only under disclosure.

Required labels:

```txt
submitted_by
institution_type
funding_disclosure
intended_audience
political/civic/commercial content flag
provenance
```

## Public Alignment Use Case

The legitimate form:

```txt
publicly evaluate synthetic media, civic narratives, future artifacts, and institutional claims through transparent, adversarial, human-in-the-loop judgment.
```

The dangerous form:

```txt
governments throw propaganda into a paid swipe machine and call the results democratic legitimacy.
```

The dangerous form is vetoed.

## Democracy Framing

Use careful language.

Better:

```txt
public participation
civic signal
open judgment layer
collective curation
```

Avoid overclaiming:

```txt
the people have decided
this is democracy
objective public truth
```

## Core UX

The app could include an `Alignment Queue` or `Public Judgment Queue`.

The user sees:

- artifact card
- source disclosure
- modal DNA
- canon argument
- prior votes hidden until after judgment
- swipe / classify / critique actions
- confidence prompt

Example prompt:

```txt
Does this deserve preservation, refinement, rejection, or containment in Slop Trough?
```

## Possible Interaction Flow

```txt
Submission enters queue
→ source/provenance attached
→ public review begins
→ user classifies / critiques
→ Caechat Gate evaluates
→ curators review disputed cases
→ reward given for validated judgment
→ artifact routes to ITEM, refinement, archive, or Slop Trough
```

## North-Star Use

The twin-app ecosystem becomes a public sorting machine:

```txt
ITEM preserves what survives judgment.
Slop Trough exposes what fails judgment.
The public participates, but curation prevents mob collapse.
```

## Implementation Notes

A v0.1 version should not include cash payments.

Start with:

- non-transferable Golden Dust
- curator reputation
- public ranking badges
- contribution history
- transparency logs

Payments can be explored later only with legal, anti-fraud, anti-bot, and labor-ethics review.

## MVP Components

```txt
Public Judgment Queue
Artifact card
Source disclosure label
Swipe/classification controls
Critique box
Golden Dust reputation ledger
Manipulation flagging
Curator review queue
Routing outcome: ITEM / refine / reject / Slop Trough
```

## Final Principle

The public should not be paid to consume slop.

The public should be invited to help distinguish canon from slop.

That distinction is the product.
