# ITEM Mobile Brand Reference

## Source Direction

The latest mobile mockup shows ITEM as an iPhone home-screen app: black field, gold orbital dust, rounded-square app icon, golden horn/orbit symbol, and clean `ITEM` label underneath.

This should become the v0.1 public adoption visual direction.

## Strategic Meaning

The mockup is important because it reframes ITEM from abstract myth or isolated logo into a plausible consumer app.

It communicates:

- phone-native public adoption
- luxury black/gold restraint
- cosmic archive identity
- sacred-industrial canon system
- quiet permanence rather than loud spectacle

## Salt-Grain Constraint

The app visual identity should invite participation in a civilization-design archive. It must not imply that ITEM is currently a literal Dyson-swarm construction platform.

Primary public meaning:

> Open the ITEM app to browse, submit, rank, collect, and preserve the 10,000 canon.

## Icon Direction

### Visual Components

- black rounded-square app icon
- thin dark glass / polished obsidian background
- gold horn or folded orbital mark
- central light point
- faint circular orbital geometry
- minimal surface detail at small size
- no excessive text inside the icon

### Production Rule

At real mobile sizes, the icon must remain legible at:

```txt
1024px
512px
180px
120px
60px
40px
```

The symbol should survive even when details vanish.

## Home Screen Impression

The app should feel like:

```txt
museum vault
+
cosmic observatory
+
luxury archive
+
public canon portal
```

Not:

```txt
crypto casino
AI slop feed
sci-fi game clone
random prompt generator
```

## App UI Requirements Derived From Mockup

### Color System

```txt
background: near-black / obsidian
primary: deep gold
secondary: antique gold / bronze
text: warm white
muted: graphite gray
accent: solar flare gold
```

### Motion Language

Use restrained motion:

- slow orbital rotations
- faint gold dust drift
- archive-card transitions
- canon status reveal
- subtle glow pulses for active ITEMs

Avoid:

- neon overload
- excessive particle storms
- frantic game UI

### Typography

Recommended direction:

- high-legibility sans for UI
- classical serif for ITEM titles and canon labels
- restrained capitalization
- museum accession style numbering

Example:

```txt
ITEM-0001
SUN AS SELF
Prime ITEM · Canonized
```

## First Screen Concept

When opened, the ITEM app should immediately present:

```txt
THE 10,000 CANON
Browse, submit, rank, and preserve civilization-scale artifacts.
```

Primary actions:

- Browse Canon
- Submit an ITEM
- View Rankings
- Learn the Canon Gate

## Product Doctrine Visible In App

The app should eventually include this line prominently:

> Generation creates abundance. Canon creates value.

And this rule:

> ITEM is not an infinite prompt stream. ITEM is a canonized registry.

## Immediate Implementation Notes

For v0.1:

- Use the black/gold home-screen mockup as brand reference.
- Build mobile-first layout before desktop expansion.
- Make the first interaction feel like entering a vault, not opening a social feed.
- Keep public language commercially legible and reality-grounded.

## Design Acceptance Criteria

A v0.1 interface passes if:

- it feels like a real mobile app
- the icon reads clearly at small size
- the first screen explains ITEM in one sentence
- the app frames ITEM as public canon participation
- users can browse, submit, and understand canon status
- visual style supports rarity and curation rather than infinite generation
