# ITEM Twin-App North Star

## Status

North-star doctrine locked.

This document defines the core product vision for the AETIMM / SLATRA twin-app ecosystem.

## /goal

```txt
Preserve the worthy.
Expose the slop.
Make the difference undeniable.
```

Expanded:

```txt
Build a twin-app ecosystem where AETIMM becomes the public canon museum for AI-native Full-Mode Artifacts, and SLATRA becomes its shadow mirror — the adversarial anti-pattern that keeps canon, quality, and meaning from collapsing into infinite synthetic slop.
```

## Twin Apps

### AETIMM

AETIMM is the path of canon.

It is the public museum, forge, registry, and canon gate for AI-native Full-Mode Artifacts.

Public promise:

```txt
Enter the Museum of Enduring Value.
```

AETIMM exists to:

- create Full-Mode Artifacts
- define modal DNA
- preserve canon-worthy works
- reward meaningful contribution
- build the 10,000 future civilization archive
- distinguish cultural permanence from synthetic abundance

### SLATRA

SLATRA is the path of consumption without judgment.

It is the shadow mirror, anti-pattern, and containment layer for low-value synthetic media.

Public promise:

```txt
Enter the Trough of Endless Consumption.
```

SLATRA exists to:

- expose slop
- contain failed submissions
- dramatize what happens when judgment collapses
- prevent AETIMM from becoming an infinite feed
- serve as contrast, satire, warning, and adversarial test environment

## Core Polarity

```txt
AETIMM = canon / museum / preservation / enduring value
SLATRA = slop / trough / consumption / endless appetite
```

Or:

```txt
AETIMM is what happens when judgment makes generation matter.
SLATRA is what happens when generation replaces judgment.
```

The first major user gesture should feel like choosing between two paths:

AETIMM

SLATRA

This is not merely navigation. It is the symbolic operating choice of the product.

## Full-Mode Artifact Standard

The new unit is not the image.

The new unit is the modal genome.

A Full-Mode Artifact may unfold into:

- image
- film
- text
- music
- simulation
- interface
- symbolic object
- physical collectible
- semantic graph
- canon dossier

The image is one phenotype.

The artifact is the genotype.

## Golden Dust Rule

Golden Dust is not equity, security, investment yield, or guaranteed money.

Golden Dust is contribution reputation / canon weight / participation credit.

Award dust for:

- coherent Full-Mode Artifact construction
- useful critique
- successful refinement
- validated duplicate detection
- manipulation detection
- canon-relevant judgment
- accepted curator contribution

Do not award dust for:

- raw uploads
- mindless swiping
- volume farming
- low-effort slop
- engagement manipulation

## Public Participation Rule

The public should not be paid to consume slop.

The public should be invited to help distinguish canon from slop.

Voting is signal, not truth.

Canon requires curation.

## Anti-Slop Laws

```txt
No trough.
No infinite feed as the core product.
No automatic praise.
No dust for uploads alone.
No canon without trial.
No engagement farming disguised as culture.
No institutional content without disclosure.
```

## Salt-Grain Constraint

AETIMM may imagine future star-scale and black-hole-scale civilizations, but it must not claim to physically build Dyson swarms, transcend heat death, or defeat thermodynamics.

Correct framing:

```txt
AETIMM is a public canon museum for AI-native multimodal artifacts that imagine future civilization-scale structures and the preservation of meaning under cosmic limits.
```

Not:

```txt
AETIMM is a literal near-term star-engineering company.
```

## Product Identity

AETIMM should feel:

- metallic
- eternal
- sacred-industrial
- curated
- black/gold
- museum-grade
- enduring

SLATRA should feel:

- wet
- gluttonous
- consumptive
- degraded
- seductive but wrong
- anti-canon

## Master Product Filter

Every future feature must answer:

```txt
Does this strengthen AETIMM, or does it accidentally turn AETIMM into SLATRA?
```

If a feature rewards infinite generation, passive scrolling, or meaningless engagement, it belongs to SLATRA or should be rejected.

If a feature strengthens canon, provenance, critique, modal structure, quality, and preservation, it belongs to AETIMM.

## Final Compression

```txt
AETIMM and SLATRA are the twin symbolic doors of the ITEM ecosystem.

AETIMM preserves what survives judgment.
SLATRA exposes what fails judgment.

The product exists to make that distinction visible, usable, and culturally real.
```
