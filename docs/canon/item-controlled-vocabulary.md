# ITEM Controlled Vocabulary

Controlled terms prevent doctrine inflation.

## Active Terms

| Term | Definition | Authority |
|---|---|---|
| ITEM | A bounded artifact record or durable object doctrine. | `README.md` |
| AETIMM | Compression principle for preserving ITEM against accumulation and entropy. | `GOVERNANCE.md` |
| Canon | Accepted ITEM material that is schema-compatible and judgment-approved. | `GOVERNANCE.md` |
| Candidate | Draft ITEM material awaiting judgment. | `docs/judgment-standard.md` |
| Archive | Retained material without active canon pressure. | `docs/judgment-standard.md` |
| Containment | Retention of high-slop-risk material without reward. | `docs/judgment-standard.md` |
| Artifact | A bounded object, record, specification, unit, symbolic system, or asset that can be judged. | `schemas/item-record.schema.json` |
| Provenance | Traceable origin, lineage, permissions, and transformation history. | `schemas/item-record.schema.json` |
| Machine-native symbolic system | A symbolic artifact designed for both human inspection and machine parsing. | `docs/artifact-classes/machine-native-symbolic-systems.md` |

| ACCRE | Alien Canonical Currency Revelation Engine; interprets value relations for ITEM currency ontology. |
| VMS | Vacuo / Mute / Singulus denomination grammar. |
| Vacuo | Reserve-class unit grammar; scarcity mapped into memory. |
| Mute | Transfer-class unit grammar; memory mapped into exchange. |
| Singulus | Singular issuance grammar; exchange mapped into fixed scarcity. |
| Minting | Canonization or issuance event; not an automatic financial claim. |

## Vocabulary Gate

A new term is rejected, contained, or routed to refinement when it duplicates an existing term, exists only for dramatic effect, lacks artifact expression, lacks provenance, or cannot be used in a schema, record, image specification, economic unit, governance rule, or candidate artifact.

Undefined abstractions are not canon.
