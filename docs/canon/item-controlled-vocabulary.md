# ITEM Controlled Vocabulary

## Purpose

This file controls ITEM terminology so the repository can distinguish durable doctrine from uncontrolled vocabulary growth.

New terms are allowed, but they must be routed, defined, and justified.

## Tier 0: Constitutional Terms

These terms control the repository and should remain stable.

- ITEM: discrete preservable artifact opposed to unbounded temporal decay.
- TIME: continuous entropic substrate in which ITEMs must persist.
- AETIMM: durable canon-facing ITEM orientation.
- SLATRA: low-signal or anti-canon material requiring containment or transformation.
- canon: accepted durable doctrine or artifact record.
- slop: material that rewards volume, vagueness, or aesthetic excess without structure.
- artifact: a bounded object, record, specification, unit, or asset that can be judged.
- provenance: traceable origin, lineage, permissions, and transformation history.
- lineage: relationship between a record and prior source materials.

## Tier 1: Economic Terms

These terms are allowed in economic doctrine and artifact records.

- ACCRE: Alien Canonical Currency Revelation Engine; interprets value relations for ITEM currency ontology.
- VMS: Vacuo / Mute / Singulus denomination grammar.
- Vacuo: reserve-class unit grammar; scarcity mapped into memory.
- Mute: transfer-class unit grammar; memory mapped into exchange.
- Singulus: singular issuance grammar; exchange mapped into fixed scarcity.
- minting: canonization or issuance event; not an automatic financial claim.
- value signal: structured evidence that an artifact may have cultural, symbolic, technical, or market relevance.

## Tier 2: Process Terms

These terms control repository movement.

- submission: incoming material before review.
- candidate: promising material awaiting judgment.
- refinement: compression of useful material into stronger structure.
- judgment: scoring and routing under `docs/judgment-standard.md`.
- canonization: repository event moving a schema-valid record into canon.
- archive: preservation without active canon status.
- deprecated: superseded material retained for provenance.
- containment: retention of high-risk low-signal material without reward.

## Tier 3: Experimental Terms

Experimental terms may appear only in candidates, research notes, or contained material until promoted.

Promotion requires:

1. definition
2. route
3. schema or artifact expression
4. reason it cannot use an existing term
5. judgment result

## Vocabulary Gate

A new term should be rejected or contained when it:

- duplicates an existing term
- exists only for dramatic effect
- lacks a route
- lacks artifact expression
- increases ambiguity
- cannot be used in a schema, record, UI, image spec, economic unit, or governance rule

## Mechanical Review Question

For every new term, ask:

```txt
Does this term reduce entropy inside the repository?
```

If not, route it to refinement or containment.
