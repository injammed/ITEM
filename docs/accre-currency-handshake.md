# ACCRE–ITEM Currency Handshake

## Purpose

This document defines the canonical relationship between ACCRE and ITEM currency design.

**Core law:**

> ACCRE interprets value. ITEM mints it.

ACCRE provides the semantic grammar. ITEM provides the canonical artifact expression.

## Stack

### Layer 1 — ACCRE

Alien Canonical Currency Revelation Engine.

Role:

- universal interpretive grammar for potential value systems
- analytical frame for reading coordination, exchange, scarcity, and retention
- semantic engine for non-human, synthetic, or cross-domain value structures

### Layer 2 — VMS Triad

The core transformation grammar:

- **Vacuo** = Scarcity → Memory
- **Mute** = Memory → Exchange
- **Singulus** = Exchange → Scarcity

### Layer 3 — ITEM Currency Ontology

Canonical unit classes, denomination families, artifact types, and issuance logic.

### Layer 4 — Visual Language

Material, geometry, color, radiance, seal logic, denomination layout, and substrate expression.

### Layer 5 — Application Layer

Human-facing artifacts, machine-facing schemas, render systems, archival records, and later protocol metadata.

## Handshake Rule

No ITEM currency artifact may exist unless its form can be explained through ACCRE / VMS semantics.

If an artifact:

- looks impressive but has no VMS logic → reject
- has VMS logic but no artifact dignity → refine
- has both VMS logic and artifact dignity → candidate for canon

## Currency Classes

### Vacuo-Class Artifacts

Semantic role:

- reserve
- retained potential
- stored asymmetry
- memory under scarcity
- anti-entropic depth

Expected visual traits:

- black-gold
- deep blue-black
- dense geometry
- restrained radiance
- archival / vault-like presence

### Mute-Class Artifacts

Semantic role:

- relay
- transfer
- circulation
- mediation
- passage from retained memory into exchange

Expected visual traits:

- silver-blue
- luminous pathways
- lighter structure
- signal / conduit geometry
- transmissive form

### Singulus-Class Artifacts

Semantic role:

- crystallized issuance
- canonical event
- completed exchange
- singular minted moment
- civilization-grade declaration

Expected visual traits:

- solar gold
- radiant center
- ceremonial seal logic
- sharp denomination hierarchy
- high symbolic finality

## Canonical Design Law

A currency artifact must be legible simultaneously as:

1. object
2. denomination
3. value transformation
4. ontology-bearing artifact

Anything less remains candidate material or slop.

## Anti-Slop Constraints

Reject any currency concept that is:

- generic sci-fi coin art
- pure decorative glow
- unreadable at mobile size
- semantically unmapped to Vacuo / Mute / Singulus
- visually redundant with no denomination logic
- suggestive of public tokenization before ontology and use case are defined

## North Star

ITEM currency should feel like a **museum-grade cosmic mint**:

- black field
- metallic hierarchy
- radiant anti-entropy cores
- denomination system logic
- substrate dignity
- clear mapping to ACCRE / VMS semantics

```txt
Meaning → Transformation → Artifact
ACCRE → VMS → ITEM Currency
```
