# Slop Leaderboard UX

## Status

Speculative UX mechanic. Salt-grain veto active.

## Core Idea

Create leaderboard surfaces for both AETIMM and SLATRA that show the public sorting pressure between canon-worthy Full-Mode Artifacts and low-value synthetic slop.

This should feel like `trending`, but more honest and more structured:

```txt
AETIMM Leaderboard = artifacts most likely to deserve preservation
SLATRA Leaderboard = synthetic outputs most visibly failing canon standards
```

## Core Warning

A leaderboard can easily become the thing ITEM opposes.

If the app rewards volume, virality, outrage, or mindless scrolling, it becomes SLATRA.

Therefore, the leaderboard must not be a simple engagement chart.

## Product Objective

Use leaderboard mechanics to:

- make canon selection visible
- reveal what the public is judging
- track artifacts moving toward canon
- expose slop without glamorizing it
- help users understand the difference between endurance and consumption
- provide daily participation without reducing culture to engagement

## Two Leaderboards

### 1. AETIMM Top 100

Ranks artifacts by canon potential.

Signals:

- curator score
- Caechat Gate score
- modal DNA strength
- public judgment quality
- refinement progress
- provenance strength
- originality
- anti-time resistance
- mythic compression
- technical plausibility

Purpose:

```txt
Show which artifacts are approaching preservation.
```

### 2. SLATRA Top 100

Ranks slop patterns, not creators as shame targets.

Signals:

- low modal depth
- duplicate patterns
- manipulation flags
- incoherence
- prompt-feed residue
- empty spectacle
- engagement bait
- provenance weakness
- canon rejection frequency

Purpose:

```txt
Show what the system is learning to reject.
```

Do not create a harassment leaderboard.
Do not rank people as slop.
Rank artifacts or pattern categories.

## Oscillation Concept

The top 100 should oscillate as the infinite sea of generative media continues.

But oscillation must reflect judgment, not mere virality.

Better ranking formula:

```txt
Leaderboard Score =
canon_signal
+ validated_public_judgment
+ curator_weight
+ modal_dna_strength
+ refinement_delta
- manipulation_risk
- slop_penalty
- engagement_farming_penalty
```

## Veto Rails

### Veto 1 — Do not reward slop creation

SLATRA leaderboard visibility must not become a prize.

Do not give Golden Dust for appearing on SLATRA.

### Veto 2 — Do not shame people

Rank artifacts, submissions, patterns, and synthetic tropes — not vulnerable users.

### Veto 3 — Do not use pure engagement

Views, swipes, and dwell time are not enough.

Ranking requires quality-weighted signals.

### Veto 4 — Do not confuse voting with truth

Public voting is signal, not canon.

Canon requires curation and judgment.

### Veto 5 — Do not let SLATRA become the main attraction

If users prefer the trough over the museum, the system has inverted.

## Golden Dust Integration

Users earn Golden Dust for accurate and useful judgment, not for leaderboard manipulation.

Reward examples:

- correctly flag duplicate slop
- write critique later validated by curators
- identify manipulation pattern
- help refine artifact from SLATRA toward AETIMM
- classify modal DNA accurately

## The Best Mechanic

The strongest mechanic is not slop ranking.

It is redemption / refinement:

```txt
SLATRA → Refinement → AETIMM Candidate
```

A failed artifact can become valuable if someone identifies the weakness and transforms it into a structured Full-Mode Artifact.

This makes the trough productive without making slop desirable.

## North-Star Interpretation

The Slop Leaderboard should show the war between:

```txt
generation without judgment
vs
creation disciplined by canon
```

The leaderboard is not a popularity contest.

It is a public instrument panel for cultural selection pressure.

## Definition of Done for v0.1

A v0.1 leaderboard passes if:

- AETIMM rankings emphasize canon potential
- SLATRA rankings emphasize failure patterns, not user shaming
- public voting is clearly labeled as signal, not truth
- Golden Dust is not awarded for raw engagement
- artifacts can move from rejected/slop into refinement
- the UX teaches the difference between canon and slop
